# Save Ottoman

Static browser game. Open `index.html` locally (double-click, or serve the folder, e.g. `python3 -m http.server` from the repo root).

If GitHub Pages is enabled on this private repo, the site URL requires you to be signed in to GitHub with access to the repository (private Pages is not publicly reachable without login; GitHub Pro may be required to publish private repos).

Live site (GitHub Pages): https://acalayir.github.io/SaveOttoman/
